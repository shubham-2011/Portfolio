# Design Integrity & Brand Preservation Rule

## STRICT REQUIREMENT: NEVER MODIFY THE ORIGINAL PORTFOLIO DESIGN OR COPY UNLESS EXPLICITLY INSTRUCTED

This project has an established, approved design, typography, layout, component structure, branding, and copy. 

### Mandatory Rules for Future Tasks:
1. **Never alter visual design elements, headers, pills, badges, or typography** unless the user explicitly requests a design redesign.
2. **Preserve exact Branding & Titles**:
   - Navbar Brand: `SKM Profile`
   - Navbar CTA: `Hire Me`
   - Hero Badge: `✨ Available for Opportunities`
   - Hero Stats Labels: `Years Learning & Dev`, `Core Technologies`, `Client Focused`
   - About Section Badge: `✨ Get To Know Me`
   - Skills Section: `My Arsenal` & `Technical Skills`
   - Projects Section: `✨ Interactive 3D Showcase` & `Selected Work` (Squarespace 3D curved cylinder)
   - Education Section: `✨ Academic Milestones` & `Education & Experience`
   - Contact Section: `✨ Direct Communication` & `Get In Touch`
3. **Backend / RAG / Feature Additions Must Be Non-Invasive**:
   - Any background backend optimizations, AI enhancements, database adapters, API routes, or script tools must integrate seamlessly without changing existing UI layouts, color palettes, or visual copy.
